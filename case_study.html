Beastly Bodies and Brains

Intro:

In this case study we will be addressing whether size/body weight have an effect on Brain size while also recognizing the fact that size isn’t relevant to how smart an animal is. The research will be surrounded on answering - What the relationship between body size and Brain size is while using the animal kingdom data. The data was aggregated by Tartarelli and Bisconti from several studies and was reported as a data set of body sizes(KG) and brain weight(g) for 70 mammalian species(Tartarelli and Bisconti 2006). These data would be answering the main research question by examining two sub research questions, which are:

Research questions:

  • What is a plausible range of values for the coefficient that relates change in body weight to a corresponding change in brain weight?
  • Should humans be considered an outlier of the general brain vs. body weight relationship?

Hypothesis:

  • Null hypothesis = H0 = B1 = 0(There is no linear relationship between body weight and brain weight)
  • Alternative hypothesis:( There is a linear relationship between body wight and brain weight)

Q2: Should humans be considered an outlier of the general brain vs. body weight relationship?

We can find whether humans are outliers or not by modeling them with the rest of the mammals and see whether they stick out in a fitted graph.

Show code 
library(ggplot2)

ggplot(Brain_Body_weight_clean, aes(x = Body_weight_kg, y = Brain_weight_g)) +
  geom_point(aes(color = Species == "Human"), size = 3) +
  geom_smooth(method = "lm", se = FALSE, color = "pink") +
  labs(x = "Body Weight (kg)", y = "Brain Weight (g)") +
  scale_color_manual(values = c("black", "red"), labels = c("Other Mammals", "Human")) +
  theme_minimal()

There is a scale issue with this graph since the line is being pulled upward by extremely large mammals which makes humans seem like they are not an outlier but to truly know whether they are an outlier or not we will have to compute a log log model which will compress the huge range of weights so we can see the difference better.

Show code 
ggplot(Brain_Body_weight_clean, aes(x = log(Body_weight_kg), y = log(Brain_weight_g))) + 
  geom_point(aes(color = Species == "Human"), size = 3) +
  geom_smooth(method = "lm", se = FALSE, color = "green") +
  scale_color_manual(values = c("black", "red"), labels = c("Other Mammals", "Human")) +
  labs(x = "Log Body Weight (kg)", y = "Log Brain Weight (g)") +
  theme_minimal()

Even after the log log someone can argue that humans dont deviate that much from the rest of the mammals. In order to further determine whether humans are outlier or not, we will have to perform a prediction interval analyses to find the usual and unusual range through a 95% Confidence Interval.

Show code 
model_predict <- predict(model, newdata = data.frame(Body_weight_kg = 62),
        interval = "prediction")
head(model_predict)
       fit       lwr      upr
1 470.3277 -2616.984 3557.639

Results 2:

  • From the prediction interval we get that a brain weight is around 470.32g, and the predicted 95% Confidence interval is between the intervals(-2616.98g, 3557.64g). The mathematical equation for it is also \[y^​±t∗⋅SEprediction​\] where we will have to find the residual variance but we can just use the rcode to make it easier and quicker.

  • The data shows that a human has 62kg body weight and 1320 g brain weight, so technically 1320g isn’t an unusual number since its falls within the intervals. However humans still will lie above the fitted regression line.

  • Once we plug in our slope and intercept from summary table as well as the 62kg human body weight to the linear equation, we get a different answer.

\[ Y = b_0 + b_1 \cdot \text{Body\_weight\_Kg} \]

\[ Y = b_0(465.88816) + b_1(0.07161) \cdot (62) = 463.13g \] The observed human brain weight is 1320 g, which is substantially larger than predicted by the model. This calculation shows a typical mammal around the same body weight as a human is predicted to have a brain weight of 463.13g which is not the case for humans, which makes them an outlier in a sense.
