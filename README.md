# Brain and Body Weight in Mammals: A Linear Regression Analysis

## Overview

This project investigates how mammalian body weight relates to brain weight using linear regression in R.

## Research Questions

- Does body weight predict brain weight?
- Are humans an outlier compared to other mammals?

## Methods

- Data Cleaning
- Exploratory Data Analysis
- Linear Regression
- Log Transformation
- Model Diagnostics
- Prediction Intervals

## Key Findings

- Body weight and brain weight have a positive relationship.
- Log transformation substantially improved model assumptions.
- Humans exhibit larger brain weights than predicted by body size alone.

## Skills

R • tidyverse • ggplot2 • Linear Regression • Statistical Modeling

## Data:

This project uses the **Mammal Brain and Body Weight** dataset, which was obtained from a publicly available source provided for educational use. The dataset contains mammalian species, body weight (kg), and brain weight (g) measurements compiled from published research.

Original source referenced in the analysis:

* Tartarelli, G., & Bisconti, M. (2006). *Trajectories and Constraints in Brain Evolution in Primates and Cetaceans.*
